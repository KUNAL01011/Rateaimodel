🔑 Authentication

RateAI uses Google OAuth 2.0 for user identity and JWT Bearer tokens for API authorization. Public endpoints (browse, search) require no auth. Write operations (submit review, save tools, list a model) require a valid session token.

1
Google OAuth
User signs in via accounts.google.com. Google returns an ID token.
2
Token Exchange
POST the Google ID token to /api/auth/google. Receive a RateAI JWT.
3
Bearer Auth
Include Authorization: Bearer <jwt> on protected requests.
POST /auth/google Exchange Google ID token → RateAI JWT
Request Body
JSON 
{
  "idToken": "eyJhbGciOiJSUzI1NiIsInR5c..."  // Google ID token
}
Response 200
JSON 
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresIn": 86400,
  "user": {
    "id": "u_01j8xk...",
    "name": "Kunal Kumar",
    "email": "kunal@example.com",
    "avatar": "https://lh3.googleusercontent.com/...",
    "verified": true
  }
}
ℹ️
Frontend hook: useAuth() → signInWithGoogle() triggers the Google OAuth popup and calls this endpoint automatically. The JWT is stored in a httpOnly cookie. Set sameSite: strict and secure: true in production.

🔍 Search & AI Recommendation

Full-text search with filter support, and an AI-powered natural language recommendation engine that matches tools to user intent.

GET /search Full-text search with multi-filter support
Query Parameters
Param Type Req? Description
q string opt Search query string. Searches name, description, tags, category
types string[] opt Comma-separated ToolTypes.
LLMImageVideoAudioCodeAgentBot
pricing string[] opt Comma-separated PricingModels.
FreeFreemiumPaidOpen Source
hasApi boolean opt Filter to tools with a public API
isOpenSource boolean opt Filter to open-source tools only
minRating number opt Minimum community rating (0–5)
sort string opt
ratingnewestpopulartrending
page integer opt Default: 1
limit integer opt Default: 20, max: 50
Example
HTTP 
GET /v1/search?q=coding&types=LLM,Code
  &pricing=Freemium,Free&hasApi=true
  &sort=rating&page=1&limit=20
Response 200
JSON 
{
  "data": [ /* AITool[] */ ],
  "meta": {
    "query": "coding",
    "total": 47,
    "page": 1,
    "totalPages": 3,
    "filtersApplied": {
      "types": ["LLM", "Code"],
      "pricing": ["Freemium", "Free"],
      "hasApi": true
    }
  }
}
POST /recommend AI-powered natural language tool matching
Request Body
JSON 
{
  "prompt": "I need to generate product images
   with text overlays for marketing",
  "limit": 4,           // optional, default 4
  "budget": "free",    // optional: "free"|"paid"|"any"
  "context": {         // optional user context
    "experienceLevel": "developer",
    "useCase": "marketing"
  }
}
⚡
Implementation note: This endpoint calls the Anthropic Claude API (claude-sonnet-4-6) with a system prompt and the full tool index to perform semantic matching. Cache aggressively — typical p95 latency is ~1.8s.
Response 200
JSON 
{
  "recommendations": [ /* AITool[] */ ],
  "reasoning": "Based on your request for
   product images with text, I matched
   tools that excel in that area...",
  "matchScores": {
    "midjourney-v6": 0.94,
    "stable-diffusion-3": 0.88
  }
}

🚨 Errors & Status Codes

All errors return a consistent JSON shape. Use the error code field for programmatic handling — never rely on message strings.

Error Shape 
{
  "error": "VALIDATION_ERROR",    // machine-readable
  "message": "body must be ≥ 50 chars",
  "field": "body",               // optional, for 422
  "statusCode": 422
}
200
OK
Success. Body contains data.
201
Created
Resource created (review, submission).
400
Bad Request
Malformed JSON or invalid query params.
401
Unauthorized
Missing or expired JWT. Re-authenticate.
403
Forbidden
Valid JWT but insufficient permissions.
404
Not Found
Tool/review slug doesn't exist.
409
Conflict
Duplicate review from same user.
422
Unprocessable
Validation failure. Check field.
429
Rate Limited
Too many requests. See Retry-After header.
500
Server Error
Internal error. Retry with backoff.
